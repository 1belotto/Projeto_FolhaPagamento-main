# Fontes editáveis dos diagramas

Os arquivos `.mmd` usam Mermaid e podem ser abertos em um editor compatível ou em https://mermaid.live.
Compare as fontes com as figuras do PDF `Modelagem_UML.pdf` antes de substituir as figuras finais.
A fonte de casos de uso é uma representação simplificada para edição; o PDF é a referência visual aprovada pela equipe.
